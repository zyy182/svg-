## 2. 运行与命令协议

从工程根目录运行：

```sh
python3 main.py
python3 -m svg_editor
python3 main.py --file examples/demo.svg
python3 main.py --script examples/demo.commands
```

`--file` 启动时读取文档；`--script` 执行 UTF-8 命令文件，遇到第一条错误立即停止并返回 1。交互模式遇到输入错误会显示原因并继续接受命令。正常结束返回 0，发生命令错误或输入结束时仍未保存返回 1，Ctrl+C 返回 130。管道输入不打印交互提示符。

| 命令 | 功能与用法 |
| --- | --- |
| `new [宽 高] [--force]` | 创建画布，默认 800×600，成功后清空历史 |
| `open "文件.svg" [--force]` | 读取并验证 SVG，成功后替换文档与清空历史 |
| `save ["文件.svg"]` | 原子保存，首次保存需指定路径；不清空历史 |
| `add 类型 [id=ID] [parent=组ID] 属性=值 ...` | 创建图形；ID 未指定时自动分配 n1、n2… |
| `move ID dx dy` | 在父坐标系中平移元素或整个分组 |
| `scale ID sx [sy [cx cy]]` | 缩放，默认 sy=sx、中心 (0,0)，比例须大于 0 |
| `group 组ID 元素ID ...` | 将连续同级元素分组；成员顺序以原绘制顺序为准 |
| `ungroup 组ID` | 解除分组，将变换和继承属性传递给子节点 |
| `delete ID` | 删除元素；分组删除包括全部后代 |
| `set ID 属性=值 ...` | 修改属性；`text=` 修改文本；禁止修改 ID |
| `unset ID 属性 ...` | 移除已有可选属性，不能移除必需几何属性 |
| `tree` | 按实际层级和绘制顺序输出文档树 |
| `show [ID]` | 无 ID 时输出 SVG；指定 ID 时输出元素 JSON |
| `undo` / `redo` | 撤销或重做一次编辑 |
| `history` | 显示可撤销与可重做操作及顺序 |
| `status` | 显示文件路径、未保存状态、元素数与历史数量 |
| `help [命令]` | 输出完整帮助或指定命令帮助 |
| `quit [--force]` | 退出；未保存时先保存或显式放弃修改 |

共有 19 个命令。`new`、`open`、`quit` 在存在未保存修改时要求先保存，或明确使用 `--force`。普通编辑成功才进入历史；新建与打开属于会话切换，不可撤销。保存保留历史。只读查询不进入历史。

### 基础图形与属性

| 类型 | 必需属性 | 可选几何属性 |
| --- | --- | --- |
| rect | width、height | x、y、rx、ry |
| circle | r | cx、cy |
| ellipse | rx、ry | cx、cy |
| line | 无 | x1、y1、x2、y2 |
| polyline | points，至少 2 对坐标 | 无 |
| polygon | points，至少 3 对坐标 | 无 |
| text | 无 | x、y；文本由 `text=` 指定 |
| g | 无 | 空分组，可通过 parent= 向组内创建元素 |

未指定的坐标默认为 0。尺寸和半径可以为 0，不能为负；画布宽高必须大于 0。数值必须有限，支持 SVG 十进制与科学计数格式。ID 以字母或下划线开头，后续可含字母、数字、下划线、点、冒号及连字符；`root` 保留作根节点。

所有元素支持 `fill`、`stroke`、`stroke-width`、`opacity`、`fill-opacity`、`stroke-opacity`、`stroke-linecap`、`stroke-linejoin`、`stroke-dasharray`、`fill-rule`、`font-size`、`font-family`、`font-weight`、`text-anchor` 与 `transform`。颜色格式支持名称、十六进制、rgb/rgba、none 与 currentColor；颜色名称的实际渲染遵循浏览器 SVG 解释。透明度为 0…1，字重支持 normal/bold/bolder/lighter 及 100…900。

空格、特殊字符与路径采用 shell 风格引号解析：

```text
add text id=caption x=30 y=40 text="中文 & SVG <示例>" font-size=24
add polygon id=tri points="0,0 30,50 60,0" fill="#336699"
set caption text="新的文字"
save "含 空格的文件.svg"
```

只支持整行 `#` 注释，颜色中的 `#` 不会被识别为注释。XML 转义由标准库完成。

## 3. 架构与软件设计

```text
main.py / svg_editor.__main__
         ↓
cli.py：交互循环、命令解析、输出与错误提示
         ↓
editor.py：文档生命周期、事务性编辑、历史与保存状态
       ↙   ↘
model.py   storage.py：SVG 解析、序列化与原子文件保存
    ↓          ↓
Document ← 文档与文件的转换
    ↓
Node：基础图形与分组构成树
    ↓
transforms.py：有限数值、仿射矩阵与 SVG transform
```

| 文件 | 责任 |
| --- | --- |
| svg_editor/cli.py | 将文本命令解析为应用服务调用；集中处理用法、交互与未保存保护 |
| svg_editor/editor.py | 统一提交成功编辑；维护 undo/redo、文件路径与保存基线 |
| svg_editor/model.py | 管理树、ID、属性、绘制顺序与分组规则，不依赖终端或文件系统 |
| svg_editor/transforms.py | 解析和组合仿射变换，并验证数值 |
| svg_editor/storage.py | 校验支持的 SVG 子集，并在文件和模型间转换 |
| svg_editor/errors.py | 定义可向用户解释的业务错误 EditorError |
| tests/ | 模型、持久化、应用服务、CLI 与回归验证 |

### 设计取舍

**职责分离与低耦合。** CLI 不直接修改模型，文件系统访问集中在持久化层。模型可独立测试；应用服务可用于其他界面。输入错误通过统一异常传播，由 CLI 转换成可理解的提示。

**树形组合。** 分组和图形使用同一个 Node 数据结构：g 有子节点，基础图形没有子节点。结构显示、查找、删除子树和序列化围绕同一树实现，避免同时维护独立层级表而造成不同步。图形差异通过类型与属性表表达，不建立没有额外行为的类层级。

**命令分派。** CLI 使用处理函数映射，各处理函数校验参数后调用 Editor。此处没有为每条命令建立独立类，因为现有规模不需要增加该复杂度。

**快照式撤销（Memento 思路）。** 为小型课程工程优先保证正确性。编辑在文档副本上执行，整体验证通过后替换当前文档，并保存操作前快照。失败时直接丢弃副本。相比为删除、分组、解组逐个编写逆操作，快照更容易完整恢复属性、层级与绘制顺序。默认保存最近 100 次编辑，代价是每次编辑 O(N) 时间、历史 O(HN) 内存；适合小型文档，不适合大规模专业编辑。

**事务边界与文件安全。** 读取先完成解析和验证再替换当前文档。保存先写同目录临时文件，再使用 os.replace 原子替换目标文件；成功后才更新保存基线。失败操作不会误报成功。清理失败不会覆盖原始保存错误。

### 模型不变量

1. ID 唯一，根 ID 保留。
2. 非根节点只有一个父节点，不允许循环或重复引用。
3. 子节点顺序就是 SVG 绘制顺序。
4. 只有分组包含子节点，只有 text 包含文本。
5. 几何参数与已支持属性合法，数值有限。
6. 失败编辑不改变文档、历史或保存状态。
7. 撤销再重做恢复同一文档内容。
8. 支持范围内保存再读取保持图形、属性、文本、层级和变换一致。

## 4. 变换、分组与文件兼容边界

移动和缩放使用 SVG 仿射变换，不直接改写图形坐标。矩阵采用 `matrix(a b c d e f)`：`x'=ax+cy+e`，`y'=bx+dy+f`。新变换左乘已有变换，因此作用于父坐标系。父分组自身存在变换时，最终屏幕位置还会受祖先变换影响。

例如 `move shape 10 20` 后 `scale shape 2`，已有平移也会被缩放，最终矩阵为 `matrix(2 0 0 2 20 40)`。`scale shape 2 2 10 20` 表示以父坐标系中的 (10,20) 为中心缩放。

分组只能包含连续的同级成员。跨父节点或不连续的元素直接拒绝，避免隐式改变绘制顺序。组可嵌套，可整体编辑和删除。解组会组合组与子节点的变换，复制继承属性，并解析相对字重 bolder/lighter，以保持解组前后字重。组 opacity 不为 1 时拒绝解组，因为组整体透明度作用于合成结果，直接复制给重叠子图形不能等价保持外观。

读写支持七类基础图形及 g、根 width/height/viewBox/version 和列出的呈现属性。接受标准 SVG 命名空间或全文件无命名空间，拒绝混合与其他命名空间；缺失 ID 自动补齐并避开已有 ID。根宽高缺失时使用项目默认的 800×600。几何属性和画布宽高可导入 px 单位，规范化为用户单位；其他单位或百分比尺寸不支持。

导入 transform 支持 matrix、translate、scale、rotate、skewX 与 skewY；多个函数之间要求空格或逗号，数值之间要求空格或逗号。导入允许 SVG 合法的零或负 scale；CLI 的 scale 命令只接受正比例。

不支持 path、image、use、defs、滤镜、CSS style/class、外部引用、动画、tspan 或富文本。遇到这些内容明确报错，不静默丢弃。不支持带 DOCTYPE/ENTITY 的 XML；文件必须为 UTF-8，可有 BOM；XML 注释不保留。保存采用紧凑 XML，以避免自动缩进改变纯空白文本。

限制：文件读写不超过 5 MiB、最多 10000 个元素、128 层嵌套、100 步撤销历史。导出也检查大小，防止产生本编辑器无法再读取的文件。仅在本机 macOS / Python 3.9.6 验证过，其他平台尚未实际测试。
